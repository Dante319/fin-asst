Drop a file in

CSV, Excel (.xlsx) and PDF are all accepted. Amex, Simplii (CSV, credit-card PDF and chequing PDF) and EQ Bank (PDF) are recognised automatically; any other CSV or Excel file with a header row falls back to a column-guessing parser. PDF statements are checked against their own stated balance before anything is saved, and refused if the numbers do not add up. Re-importing a file you have already loaded, or two exports that overlap by a few days, adds nothing twice.
